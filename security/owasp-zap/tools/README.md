Este arquivo (`ZAP_2.17.0_Crossplatform.zip`) não é versionado no git (ver
`.gitignore`). Foi baixado da release oficial do OWASP ZAP no GitHub:
https://github.com/zaproxy/zaproxy/releases/tag/v2.17.0

É a versão "Crossplatform": sem instalador, só os arquivos do programa.
Requer Java (JDK/JRE 11+) já instalado na máquina.

Para instalar, descompacte este zip em um local permanente, por exemplo:

    C:\ZAP

O resultado será uma pasta como `C:\ZAP\ZAP_2.17.0\`, contendo `zap.bat`
(Windows) e `zap.sh` (Linux/macOS).
